# Calle Heat
![ReadMeImg](/app/assets/ReadMeImg.png)

Calle Heat is a vibrant, modern web application built to showcase an urban street-food taco truck. Designed with an edgy street style aesthetic, it provides customers with a full interactive menu with spice levels, a location schedule across Los Angeles, a photo gallery, catering inquiry details, and operating hours.

- **Interactive Menu System**: Filterable menu categories featuring street tacos, house specialties, sides, and ice-cold drinks.

- **Dynamic Location Schedule**: Weekly calendar showcasing daily truck locations and operating hours throughout Los Angeles.

- **Modern Aesthetic & UI**: Street-culture vibe utilizing high-contrast visuals, clean typography, and responsive layouts.

- **Catering & Contact Setup**: Complete catering information and direct contact links for private events and block parties.
